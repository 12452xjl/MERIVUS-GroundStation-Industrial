## 范围与明确风险

`FleetMissionStartupPanel.qml` 是已有原生启动链的界面消费者，不创建第二套事务或授权模型。它只读取同一 Guided Controller 的 `fleetStartupWorkbench`，所有操作只调用 `performFleetStartupAction(action, expected, true)`；不直接调用 Vehicle、旧启动 API 或原生 QObject，不手填飞机、任务、启动 ID 或账号 SID。

这不是飞行放行声明。`startupPermitGranted=false` 表示没有最终 StartPermit / 安全认证，**不表示原生条件事务绝不会发送命令**。显式真发送操作可能修改起始序号、普通解锁并切换任务模式。是否允许排队仍由实际原生身份、来源、风险、整组状态与原期限逐次核对；界面不以许可字段为 false 封死已有合法条件链，也不把它改写为许可。

## 一次一个明确动作

初次链：新整组完整机载读取 → 新风险审阅 → 人工已阅 → 另一真实账号的条件批准 → 一次接管有限依据 → 明确请求 Seq0 / 普通 ARM / MISSION 事务。另有各阶段精确停止 / 撤销动作。没有自动串联、自动勾选或失败重试。

地面再审链：从当前组保留的最新实际事务重新取证 → 人工已阅新地面风险 → 新独立账号条件批准 → 新有限依据 → 新独立事务。只有原事务终止并排空、从未可能发送 MODE 等原生前置条件满足才可进入；不从旧观察 Run、归档报告或上一代 owner 回退取源。原已解锁成员在新事务中可以按真实冻结依据跳过 ARM，不造解锁 ACK，也不直接跳过整组屏障。

操作员先选择分支和单个动作，阅读完整标题、真实影响及缺口，再勾选确认。真发送按钮明确写出真发送；读取说明真实发送只读请求；批准说明会调用原生独立账号认证；依据接管与撤销均区别于飞行命令。现有身份入口负责主账号认证，本页不创建新登录或伪造第二人。

## 冻结与调用回执

- `snapshot` 是原 Controller 的完整三字段 `{sourceToken, identityToken, stamp}`，按下时深拷贝并在点击前严格比对。稳定 stamp 绑定实际部署组、身份、记录、各阶段来源及队列状态；自然递减的剩余时间不作为每毫秒失效依据。
- 原 Controller、来源 / 身份 token、动作和界面生命周期均冻结。换控制器 / 来源 / 身份、阶段变化、切换动作、关闭或隐藏会废弃本地确认；序号耗尽即禁用，不回绕复用。关闭只结束界面确认，不自动调用取消或停止飞机。
- 本地调用 ticket 保持到结果采纳和 `callBusy=false` 通知结束，防重复或同步重入。当前事务自身合法推进不能抹掉原调用回执。
- 统一回执的 `invoked`、`accepted`、`current`、`flightCommandReleased` 分开显示。`accepted` / 飞行排队标记为 `null` 或回执中断时明确未知，不推断没有动作；后置失源不覆盖已返回的接受事实。不自动重试或回滚。
- 接受异步事务不等于已经发出全部命令；返回后的实际阶段仍可能继续推进。`started-observed` 仅表示原范围的新 RAW 状态已观察，不是任务执行 / 完成、无线请求因果或飞机已安全停止。

## 完整风险与逐机账单

初次风险使用既有 `StartReview.current` 的公开工件；整组字段可完整展开，逐机字段按页展开，包括原因、缺口、冻结启动政策和原生物理摘要。未声称显示内部私有身份或完整 RAW 载荷。

地面风险使用新 `riskSummary` 白名单：24 字段整组、每机 8 字段、最多 32 架。只有 `available=true`、未过期、组 / 机原因均未截断，并且 review ID、epoch、previousStartup、source fingerprint 和状态与当前地面审阅相同，才可展开为本次完整风险并进行已阅。否则显示实际原因，空对象 / 空列表不当成没有风险。地面可已阅状态为 `content-ready`，与初次 `reviewable` 区分。

整组与逐机的阻断原因、未验证要求和政策不取前 N 项冒充完整；JSON 细节采用纯文本原字段名 / 原值，可换行且不会执行导入文本。每页 8 架，最多 32 架；同时只展开一个逐机完整字段块。读取、风险 / 政策、事务三类账单独立选择。未知、`null`、缺失值不补 0 或 false。

事务每机展示 `Seq0`、`NormalArm`、`MissionModeOnly` 三步的原 requestIssued、rawStateObserved、mayHaveCommitted、skippedReviewedAlreadyArmed；不把 ACK 当阶段完成。全局活动、排空、本地占用、队列和部分结果单独可见。地面事务取真实最新 child，不由 Series 的历史精简快照补造三步。

## 布局与工程边界

原宿主只放一个入口按钮，正文为 Overlay 模态窗口，不撑大固定飞行控件布局。窗口受当前应用宽高限制，正文限高滚动，关闭按钮固定在滚动区外；支持明确关闭与 Escape。所有动态文本用 `Text.PlainText`，长 ID 可折行；操作控件使用 QGC palette、最小 44 像素、可见键盘焦点及明确禁用态。翻页和焦点变化保持聚焦控件可见。

仅完成源码和限定静态核对；没有运行技能脚本、QML、认证、编译、测试、模拟器、飞控或设备。工程师仍须核验弹窗与原生账号提示叠层、键盘 / 窄屏 / 字体缩放、同 SID 换会话、过期 / 源变化 / 取消 / 同步通知、真实协议三步与部分失败、地面混合 armed 分支及硬件放行。没有新增权限或自动安全保证。
