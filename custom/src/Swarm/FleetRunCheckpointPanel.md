# Run 后台检查点与只读恢复入口

入口位于现有“运行报告/复盘”区域。`FleetRunCheckpointPanel.qml` 经 `GuidedActionsController.runCheckpointWorkspace` 访问原 `SwarmMissionOrchestrator`，只提供明确启用/停用、保存或重试、取消、打开独立历史、四条分页和选中报告；不暴露原生任务注册或执行接口。

默认不保存、不读取。操作员必须先勾选“允许本次会话持续替换固定检查点文件”，再确认启用；这包括替换上一会话同名文件，因此界面提示可先打开旧历史。确认跟随按下时的对象和界面代，关页、换源会使旧确认失效。停用只停止后续自动保存，不撤销已经受理或提交的写入。取消也是请求，不是文件未写入的证明。

状态分别显示当前代、捕获代、已保存代、未保存变化、捕获是否仍对应当前来源、写入是否已知/已提交以及读回复核。`sourceCurrent` 指本次捕获代仍当前，不表示磁盘文件已经保存或持续新鲜；界面仅对save显示此判断，打开历史时显示“不适用”，不把启动读取时的本机代次当成文件内容仍当前。失败/未知/取消均保留原生结果，不把失败自动解释成没写入。固定文件是当前全部原生保留 Run 的快照，非所有 MAVLink 报文、逐边沿事件、永久档案或断电持久性保证。

明确打开文件在独立历史槽完成全量校验。四条小摘要分页后，选择一条经后台已生成的完整 protected Run 报告送入原 `FleetMissionExecutionReportPanel` 只读报告区；该报告始终标成 `imported`，即使其来源 UUID 与当前进程相同也不恢复任务、观察器、占用、批准或控制权。读取失败保留旧历史；切换历史时旧页和选择不能指向新槽的同一索引。

复用现有报告区的滚动/焦点和完整报告显示，不创建第二套执行结果解释。新面板有明确字段说明、长标识换行、单一父滚动区、按钮忙态和取消提示。只做源码静读，未运行 UI 或文件读写。工程师须验证启用确认、持续更新时的合并/过时状态、保存与历史读取串行、停用/取消、跨重启读取、页/报告来源替换、完整报告呈现、磁盘/锁/损坏文件/资源上限以及 Qt 控件兼容性；全部未执行。

原生格式、资源上限、代与后台线程寿命详见 [SwarmMissionOrchestrator](SwarmMissionOrchestrator.md)。
