# 失败 / 取消部署后的整组只读对账界面

实现入口为 [FleetMissionDeploymentPanel.qml](../../res/Merivus/FleetMissionDeploymentPanel.qml)，控制器为 [GuidedActionsController.qml](../../res/Merivus/GuidedActionsController.qml)。这是第 426 批独立功能，不把第 425 批普通 decoded 回读差异面板、原 `StartContentCheck` 或旧部署成功记录改名作为新能力。

## 操作与来源

- 显式入口为“重新核对整组机载任务（只读）”。只接受本次原生运行中 `failed` / `cancelled` 且原传输已排空的部署；对象、目标和预期内容来自该部署的原冻结记录，不来自当前草稿。打开面板不会自动读取；界面不自动重发整个核对请求、不修复或上传。原生读取协议仍保留有次数／期限限制的丢包重试，每次发送仍核授权。
- 未预选的确认框说明先撤销旧审阅 / 审批。使用当前真实 Session 与独立 `mission.reconcile.read` 角色动作，不借用旧上传 / 启动凭据，不新增第二账号批准。实际地面状态、身份与协议条件仍由原生服务决定。
- 按下至点击、调用返回时核对控制器、当前 Episode 的值型来源 token、原部署 ID / 代次、冻结目标、身份和角色快照。控制器入口通过原生 current-scope 调用桥；真正回调接收者始终是该 Episode 的 Deployment，不向界面暴露其私有对账子对象。
- “停止本次整组对账”绑定原 requestId、runEpoch、generation 和来源 token。取消停止后续读取，保留当次已有观察，不撤回在途消息、不回滚机载任务，也不强制释放协议占用。旧请求 ID 不能选取新运行。草稿失效与原 scope 清理也明确取消该子操作，不依赖 Deployment 已取消状态再次发出通知。

## 结果表达

- `Deployment.reconciliation` 仅提供值型 30 键摘要；接受回执另有 `ok` / `requestAccepted`。最多 32 架，每机 16 键摘要。显示匹配、不同、未知、待读取 / 读取中的实际计数及占用 / 排空原因。`completed` 是本批读取结束，不是整组通过。
- 未取得完整观察的 `observedItemCount = -1` 显示“尚未取得完整观察”，不转成零项。真实完整 COUNT 0 是已观察空任务，可以与非空预期不同。完整读取但无法规范化时，数量已不同可显示 count-only 不同；数量相同仍显示未知，不能据数量相同判定内容相同。没有结果 / 空哈希不代表没有差异。
- 默认每机只展示状态、预期与当次观察数量、原因。按需展开原请求运行、代次、读取 scope、原生操作 ID、规范化哈希、RAW 指纹和单调观察时标；详情通过 `Loader` 惰性创建。所有摘要纯文本、允许换行，复用 QGC 色板、键盘焦点及按钮最小高度。操作状态不只依赖颜色。
- 当前入口真实来源为 `independent-diagnostic-raw-int-history`，只提供状态 / 计数 / 哈希摘要，**没有新 RAW 逐字段差异明细**。第 425 批普通 decoded 的最多 64 行差异仍保留为独立历史诊断，不能当作本次 RAW 结果。
- 最大原冻结预期总量及完整实际观察累计量分别为 8192 项、每机最多 2048 项，原生总采集期限 120 秒；容量边界不保证整组及时完成。观察总项数只累计完整实际读取，可能与原预期不同；预算耗尽的剩余目标不能合成成功结果。界面不自行延长原生期限，也没有用于此功能的自动请求计时器。

## 互锁与不提供的权限

- 对账 active / reservationHeld / transportDraining 纳入控制器通用读取互锁及界面上传、刷新、内容核对、快照检查和启动审阅的禁用条件。对账自己的原生上下文回调只检查其它读者与启动操作，不把自己的合法占用当作外部冲突。
- 原 `StartContentCheck` 仍要求其原有成功部署依据；新对账不会生成该凭据，不更新它的通过状态或有效期，不恢复旧风险审阅 / 上传 / 启动批准。
- 逐机顺序读取不证明远端整组原子快照、无线请求因果、硬件身份真实性、此刻机载内容或持续新鲜度。即使全部匹配，`currentOnboardContentsProven`、`startupPermitGranted`、`executionVerified`、`flightCommandReleased`、`executable` 仍为 false。没有自动重新上传任务、任务修复、解锁、起飞、开始任务或降落动作；读取请求的受限协议重试不属于任务写入。
