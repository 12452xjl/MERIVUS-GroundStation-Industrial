# FleetUserTaskTemplatesPanel 用户草案模板入口

位于真实任务规划器滚动内容内，默认收起；仅依 `controller.userTaskTemplates` 窄门面，不获得 Registry、实际 Draft 或用户库原生 QObject。内建只读目录继续原样显示。按 UI/UX 静态规则沿 QGC 主题、可见字段标签、就地错误、44px控件下界、键盘 StrongFocus／焦点可见信号、四条分页及换行；用户禁止运行，因此没有搜索脚本、布局渲染、QML执行或交互测试。

操作顺序：在原规划器完成当前字段编辑→填写名称／分类／说明→明确捕获为新模板或原最新版本的新版本；选择模板后可分页查看其全部版本、选择精确旧版本、只追加元数据版本。保存需要原完整路径覆盖确认，重开需要原路径独立库替换确认，文件动作显式且等待原生真实终态。路径、名称、选择、原库revision／job、Draft token、可见性或输入是否提交变化都使旧确认失效；按下冻结原来源，旧释放不能给新路径或新版本授确认。

预览通过 Root 的精确 native token→原完整 editingSource 查找，界面只显示有界身份／数量。复制有独立二次确认，有上一稿时还需其替换确认；只调用原 pristine 新Draft加载／原稿保留链，清datum确认，撤销旧审阅／批准。完成复制后仍须在原规划器重新补全并审阅／审批，不自动 prepare、approve、upload 或发任何飞行指令。用户文件版本不作为内建templateId，不恢复信任。

公开13字段回执中的committed保留原本地事实；文件accepted仅受理，状态与result各自标原job，save读回失败不能抹已写。共享最新原生result仅诊断展示，不恢复本页确认或源token。失联／换源／关闭不会回滚已提交文件。源文件UTC、名称及版本均未认证，完整性、hash、写入和只读预览都不等于真实飞行验证。
