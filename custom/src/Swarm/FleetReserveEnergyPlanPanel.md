# 备用待命 / 接替规划入口（432，静态交接）

## 入口和范围

复用 `FleetMissionPlannerPanel.qml` 当前成员编辑区，为 `reserve` 角色显示“备用待命 / 接替预算”；若外部更换来源 / 成员使旧编辑失效，仍保留旧输入和取消出口，不允许保存到新来源。没有新增 QML 类型、服务、地图交互、网络请求、参数写入、自动接替、上传或启动按钮。地图右键仍只添加区域顶点；既有地图预览仍只绘制主任务成员，不把备用估算伪装成已上传航线。

流程为选择备用成员 → 编辑并保存策略 → 保存备用机自身完整起点 / 返回点 → 重新生成审阅 → 查看逐机能量账单。策略和端点是两次独立本地提交，不声称一次原子提交；最终 build / review 基于一个完整草稿版本。也可以先保存端点，再填写策略。无需从实时机位或 Home 自动取值。

`reservePlan` 为 exact 8 字段：`schemaVersion=1`、`replacementVehicleId`、`standbyMode`、`standbyDurationSeconds`、`standbyConsumptionFactor`、`cruiseSpeedMetersPerSecond`、`climbSpeedMetersPerSecond`、`descentSpeedMetersPerSecond`。目标选自当前草稿所有其他非备用成员；选择目标不证明载荷、构型或能力等价。目标不再存在、改成备用或路线不适用时，由最终 build / compile 明确拒绝，不自动选其他成员。

待命方式必须选 `ground-disarmed` 或 `airborne-hold`，名称是规划假设而非飞机状态证明。时长为 0–86400 秒；系数必须显式大于 0 且不超过 10；水平、爬升、下降速度各必须显式大于 0 且不超过 1000 m/s。新建输入没有物理默认值，这些只是输入边界，不是硬件可达范围。系数表示待命耗电相对名义飞行耗电的工程声明，不是标定值；地面待命也不默认按零耗电计算。

端点复用原 `member.start/returnTo`，要求完整 WGS84 经纬度和 AMSL 海拔。备用端点独立于覆盖机的 `includeEndpoints` 开关；不借用主机端点、Home 或当前位置，也不保证障碍净空。既有执行配置编辑器仍独立，不能把其 `endAction=hold` 当作这里的待命输入。保留但未使用的历史辅助航点也不参与备用派生。

## 版本和确认

编辑会冻结实际 facade、controller、草稿选择代号、revision、备用成员 ID 和原成员内容；保存为整份策略替换，不逐字段自动提交。Root 再冻结当前实际 Draft 对象，失效旧审阅 / 审批后复核原对象和 revision，再调用原生 `setMemberReservePlan(id, policy, expectedRevision)` 或 `clearMemberReservePlan(id, expectedRevision)`。未持有 native 来源调用租约时才编辑本地 Draft，避免自己的 changed 通知使调用自失效。

备用端点首个文本修改也冻结同样身份；`setReserveEndpoints` facade 在失效旧预览后检查对象、角色和 revision，再使用既有原生 `setEndpoints`。原生接口未新增端点 CAS 参数，因调用均为同线程同步，Root 的最终核对与原生提交之间没有异步等待。端点和策略编辑彼此互锁，也与执行配置输入互锁。

未提交策略 / 端点或待确认清除纳入 `hasPendingCoordinates/inputSettled`，不能通过旧值生成审阅、批准、换成员 / 角色或恢复切换草稿。其他来源使 revision 变化时，旧编辑不可保存；保留输入，明确要求取消后重新编辑，不自动重试。关闭 / 隐藏、controller 或草稿选择变化会清除确认，不静默删除未提交文本。取消编辑仅放弃未提交输入，不恢复旧批准。

保存前必须勾选确认规划假设；清除采用独立两步确认，并提示该备用机将失去完整预算。清除只移除策略，不移除端点或改变角色。角色切换会保留策略，但仅备用角色参与备用提案；非备用角色显示保留说明。回执失源或原生返回未确认时，不宣称已经回滚可能发生的本地修改，也不自动重试。

## 预算和非执行边界

本次预算路线为备用机自身起点 → 指定主机完整已编译出航 / 作业路线 → 备用机自身返回点，按备用机声明的水平 / 爬升 / 下降速度估算并计入目标停留。不是从故障断点续飞；不验证障碍、空域净空、接替能力等价或实飞性能。原 `reserveVehicleIds` 与主任务 `assignments/members` 分离不变，备用输入以单独 `reservePlans` 传递，不将备用成员加入 active 上传 / 执行成员。

账单 `budgetDetails.basis=compiled-reserve-route-budget` 展示完整性、原因、待命与路线各分项、共同任务时间下限、返程预留和目标路线哈希。待命等效名义飞行时长为时长乘以声明系数，并额外加到飞行任务预算；未知 / 缺失仍是未知，不用旧最长主机时间代替。哈希绑定当次目标路线内容，不认证来源、物理安全或执行结果。431 原生电池来源与当前审批时效门禁保持，不因此新增授权。
